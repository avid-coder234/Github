# 📘 Basic Git Commands Guide

Welcome to the **Git Commands Guide** — a quick reference for beginners to understand and use the most common Git commands.  
This guide will help you initialize a repository, track changes, commit updates, and navigate between commits.

---

## 🧩 1. Initialize Git
Create a new Git repository in your project folder.

```bash
git init

git status

git add <filename>

git add .

git commit -m "your commit message"

git log

git log
git checkout <commit-hash>


git checkout main



--> To initialize a git 
    git init

--> To know the branch and also the files
    git status

--> to Add a file 
    git add <filename>

--> to commit something 
    git commit -m 'message likhna hai'

--> to add all the files
    git add .

--> to check all the commit history
    git log 

--> to go to a specific commit 
    git log
    copy the hash code of the commit
    git checkout <hash code>

--> to swicth back to the original 
    git checkout main
